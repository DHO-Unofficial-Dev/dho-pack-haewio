# 해위오 에디션

DHO Navigator 리소스팩입니다. 짙은 갈색 바탕에 주황 포인트로 Navigator 본창, 정보 패널, 조향·지도 HUD를 바꾸고,
항구 등불·길드 깃발·바다 부표 같은 마커와 앱 아이콘을 함께 바꿉니다.

![해위오 에디션](pack/thumbnail.webp)

## 받기

[Releases](https://github.com/DHO-Unofficial-Dev/dho-pack-haewio/releases/latest)에서 `haewio-<버전>.dho-pack`을 받습니다.
같은 이름의 `.sha256` 파일로 내려받은 파일이 맞는지 확인할 수 있습니다.

## 설치

1. DHO Navigator 2.1.4 이상을 켭니다.
2. 왼쪽 위 로고 › Navigator 설정 › 팩 탭 › `팩 설치`에서 받은 `.dho-pack` 파일을 고릅니다.
3. 설치한 팩을 켭니다. 직접 옮긴 HUD 위치·크기·투명도는 팩보다 우선합니다.

## 구성

| 구성요소 | 바꾸는 것 |
| --- | --- |
| `infoPanelSkin` | 정보 패널과 Navigator 본창 색 |
| `steeringHudSkin` | 조향 방향띠와 중앙 십자선 색·투명도 |
| `mapHudSkin` | 지도 HUD 색 |
| `markerSet` | 선박·목적지·거점 유형·개인 표식 마커 |
| `appIcon` | 창 아이콘 |

`pack/`은 1.3.0 파일을 풀어 놓은 내용입니다. 1.3.0은 DHO Navigator 2.1.x 형식이라 2.2.0 공개 Pack 도구로 다시 빌드되지
않습니다. 2.2.0 형식으로 다시 만든 2.0.0을 준비하고 있습니다.
